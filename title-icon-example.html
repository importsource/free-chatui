✨ Title Icon Customization

Try it now! Click the chat button in the bottom right corner. Notice the icon next to "Support Chat" in the header. Title icons support emojis, SVG, and image URLs - all automatically detected!

🎯 How Title Icons Work

  • Auto URL Detection: Just provide a URL - the library automatically creates an <img> tag
  • Supported URLs: http://, https://, /, and data: URLs
  • Emoji: Any emoji works out of the box
  • Custom HTML/SVG: Full HTML/SVG support
  • Auto-sizing: Images automatically sized to 24x24px
  • Smart rendering: Rounded corners for better appearance

8️⃣ Custom SVG Icon

Use your own custom SVG

title: 'Custom Chat', titleIcon: `<svg width="20" height="20" fill="white"> <circle cx="10" cy="10" r="8"/> <text x="10" y="14" text-anchor="middle" font-size="12" fill="#667eea">?</text> </svg>`

Note: Make sure SVG has proper fill/stroke colors for visibility

9️⃣ Logo Image URL

Use your company logo via URL (auto-detected!)

title: 'Your Company Support', titleIcon: 'https://your-domain.com/icon.png'

Note: URLs are automatically detected and rendered as images. No need to wrap in <img> tags!

🔟 Relative Path Image

Use relative paths for local images

title: 'Support', titleIcon: '/images/logo.png'

Relative paths (starting with /) are also auto-detected

✨ Title Icon Best Practices

Do's:

  • ✅ Use emoji for simplicity (no external files)
  • ✅ Use image URLs for brand logos (automatically detected!)
  • ✅ Match icon to your service type
  • ✅ Keep icons simple and recognizable
  • ✅ Use square images for best results (auto-sized to 24x24px)
  • ✅ Ensure icon has good contrast with header background
  • ✅ Test on both desktop and mobile

Don'ts:

  • ❌ Don't use large images (slows loading)
  • ❌ Don't use complex multi-color icons (may clash)
  • ❌ Don't forget to test on mobile
  • ❌ Don't use icons that don't match your service
