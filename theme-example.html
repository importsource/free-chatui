🎨 Complete Theme Configuration

All available theme options:

theme: { // Primary colors (used for gradients) primaryColor: '#667eea', // Main brand color secondaryColor: '#764ba2', // Secondary for gradients // Message bubbles userMessageBg: null, // null = uses primaryColor gradient userMessageColor: '#ffffff', // User message text color botMessageBg: '#ffffff', // Bot message background botMessageColor: '#333333', // Bot message text color // Header headerBg: null, // null = uses primaryColor gradient headerColor: '#ffffff', // Header text color // Chat interface chatBg: '#f7f8fc', // Chat messages area background inputBorder: '#e5e7eb', // Input field border color // Typography fontFamily: '-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif' }

How Themes Work

  • primaryColor: Used for buttons, input focus, and gradients
  • secondaryColor: Creates gradients with primaryColor
  • Auto-gradients: If userMessageBg or headerBg are null, gradient is auto-generated
  • Full control: Override any color individually
  • Font family: Change the entire interface font
