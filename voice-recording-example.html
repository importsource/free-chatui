🎤 Voice Recording Example

Record and send voice messages with social media-style bubbles

✨ Voice Recording Features

  • One-Click Recording: Click the microphone button to start/stop recording
  • Server Upload: Voice files are automatically uploaded to your server
  • Social Media Style: Voice messages appear as blue bubbles with waveform animation
  • Playback Controls: Click to play/pause voice messages
  • Duration Display: Shows recording length in seconds
  • N8N Integration: Voice files are included in the chat payload
  • Mobile Support: Works on both desktop and mobile devices
🎯 How it works:
  1. Click the microphone button to start recording
  2. Speak your message (button turns red while recording)
  3. Click again to stop recording
  4. Voice message is automatically uploaded and sent
  5. Voice appears as a playable bubble in the chat
📝 Note: Voice recording requires microphone access. The browser will prompt you to allow microphone access when you first try to record.
⚠️ Requirements: Make sure your server supports audio file uploads and returns the filename in the response. The voice files are uploaded as WebM format.

🔧 Configuration

const N8N_CHAT_CONFIG = {
  // ... other config options ...
  
  voice: {
    enabled: true,  // Enable voice recording
    language: 'en-US',
    continuous: false,
    interimResults: true,
    maxAlternatives: 1
  },
  
  fileUpload: {
    enabled: true,
    uploadUrl: 'http://localhost:8090/nexusense/api/upload',
    downloadUrl: 'http://localhost:8090/nexusense/api/files',
    maxFileSize: 10 * 1024 * 1024, // 10MB
    allowedTypes: ['audio/*', 'image/*', 'application/pdf', 'text/*'],
    maxFiles: 5,
    showPreview: true
  }
};

🎨 Voice Message Styling

The voice messages use a social media-style design with:

  • Blue bubble background (#007bff)
  • Animated waveform that pulses while recording
  • Play/pause button with smooth transitions
  • Duration display showing recording length
  • Responsive design that works on all screen sizes

📱 Mobile Experience

Voice recording works seamlessly on mobile devices with touch-friendly controls and optimized audio recording settings.
