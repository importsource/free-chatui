💡 Chat Tips & Tooltips Examples

Try it now! Wait 2 seconds and you'll see a tip appear near the chat button in the bottom right corner. Click the chat button or the X to close the tip!

1️⃣ Default Tip

Simple, helpful tip with default styling

tip: { enabled: true, text: 'Need help? Chat with us!', delay: 2000 }

2️⃣ Quick Tip

Show tip immediately (500ms)

tip: { text: '💬 Chat now!', delay: 500 }

3️⃣ Custom Color Tip

Branded tip with custom colors

tip: { text: 'We\'re online! 🟢', background: '#4caf50', color: '#ffffff', delay: 2000 }

4️⃣ Persistent Tip

Tip stays visible until manually closed

tip: { text: 'Questions? Ask us!', autoHide: false, delay: 1000 }

5️⃣ Friendly Welcome

Warm, inviting message with emoji

tip: { text: '👋 Hey there! Need assistance?', background: '#667eea', color: '#ffffff', delay: 1500 }

6️⃣ Urgency Tip

Create urgency with quick display

tip: { text: '⚡ Live support available now!', background: '#ff6b6b', color: '#ffffff', delay: 500 }

🎨 Complete Tip Configuration

All available options:

window.N8N_CHAT_CONFIG = { chatUrl: 'YOUR_N8N_WEBHOOK_URL', button: { enabled: true }, tip: { enabled: true, // Show/hide tip text: 'Need help? Chat with us! 💬', // Tip message delay: 2000, // Delay before showing (ms) autoHide: true, // Hide on first interaction background: '#ffffff', // Background color color: '#333333', // Text color shadow: '0 4px 16px rgba(0,0,0,0.15)' // Box shadow } };

Tip Behavior

  • Auto-show: Tips appear automatically after the specified delay
  • Auto-hide: By default, tips hide when user clicks the chat button or X
  • Persistent: Set autoHide: false to keep tip visible
  • Animations: Smooth slide-in and slide-out animations
  • Close button: Users can always manually close the tip

Best Practices

  • ✅ Keep tip text short and friendly (under 40 characters)
  • ✅ Use emojis to make tips more inviting
  • ✅ Set delay between 1-3 seconds for best results
  • ✅ Match tip colors to your brand
  • ✅ Test on mobile to ensure readability
