🚀 N8N Chat - Complete Example

This page showcases ALL features of the N8N Chat library in action!
Click the chat button in the bottom right to see everything working together.

💬 Toggle Button

Click the floating button to open/close the chat

💡 Helpful Tip

Wait 2 seconds to see a tooltip appear

👋 Welcome Message

Friendly greeting when you open the chat

⚡ Starter Prompts

Click prompts to send instantly - they stay visible for reuse!

👤 Avatars

Custom bot and user avatars with emoji or images

🎯 Try These Features:

  1. Wait 2 seconds - A tooltip will appear near the chat button
  2. Click the chat button - The chat window will slide open
  3. See the welcome message - A friendly greeting appears
  4. Click any starter prompt - It sends instantly without typing
  5. Click multiple prompts - Prompts stay visible for reuse
  6. Or type your own message - Use the input field normally
  7. Click the X button - Close the chat window
  8. Click the reset button - Start a fresh conversation
👀 Look at the bottom right corner to get started!

📝 Complete Configuration

Here's the exact configuration used on this page:

Chat with us! 💬', delay: 2000, background: '#ffffff', color: '#333333' } };
