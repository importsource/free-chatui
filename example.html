🚀 N8N Chat Library Examples

Example 1: Chat UI Component

The easiest way to get started - just set your chatUrl and the UI is ready!

// Initialize with UI const chatUI = new N8NChatUI({ chatUrl: 'YOUR_N8N_WEBHOOK_URL', title: 'Support Chat', placeholder: 'How can we help?' }); chatUI.init();
Note: Replace 'YOUR_N8N_WEBHOOK_URL' with your actual n8n webhook URL to see it in action!

Example 2: Client Only (Custom UI)

Use just the client if you want to build your own custom interface.

// Initialize client const client = new N8NChatClient({ chatUrl: 'YOUR_N8N_WEBHOOK_URL' }); // Send a message const response = await client.sendMessage('Hello!'); console.log(response); // Get conversation history const history = client.getHistory();

Example 3: Advanced Configuration

Customize the chat with callbacks, headers, and more options.

// Advanced configuration const chatUI = new N8NChatUI({ chatUrl: 'YOUR_N8N_WEBHOOK_URL', containerId: 'custom-container', title: 'AI Assistant', placeholder: 'Ask me anything...', showTimestamp: true, headers: { 'Authorization': 'Bearer YOUR_TOKEN', 'X-Custom-Header': 'value' }, timeout: 30000 }); // Access the client for advanced features const client = chatUI.getClient(); // Set custom session ID client.setSessionId('user-123'); // Send message with metadata await client.sendMessage('Hello', { userId: 'user-123', language: 'en' });

Example 4: Client with Callbacks

Handle messages and errors with custom callbacks.

// Client with callbacks const client = new N8NChatClient({ chatUrl: 'YOUR_N8N_WEBHOOK_URL', onMessage: (data) => { console.log('Received:', data); // Update your custom UI here }, onError: (error) => { console.error('Error:', error); // Handle error in your UI } }); // Send message client.sendMessage('Hello, how are you?');

🎯 Quick Start Guide

Step 1: Include the Library

<!-- Include both files for UI support --> <script src="n8n-chat-client.js"></script> <script src="n8n-chat-ui.js"></script> <!-- Or just the client for custom UI --> <script src="n8n-chat-client.js"></script>

Step 2: Add Container

<!-- Add a container for the chat --> <div id="n8n-chat-container"></div>

Step 3: Initialize

<script> // That's it! Just set your chatUrl const chat = new N8NChatUI({ chatUrl: 'YOUR_N8N_WEBHOOK_URL' }); chat.init(); </script>
