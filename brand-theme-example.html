🎨 Custom Brand Theme Example

See how to perfectly match the chat widget to your brand

About This Example

This page demonstrates how to create a fully branded chat experience that matches your website's design. The chat widget uses custom colors, fonts, and styling to blend seamlessly with your brand identity.

Click the chat button in the bottom right corner to see the custom theme in action!

👀 Try the Chat!

Look at the bottom right corner and click the chat button to see the themed chat widget

📝 Configuration for This Page

Here's the exact configuration used to create this branded chat experience:

window.N8N_CHAT_CONFIG = { chatUrl: 'https://your-n8n-webhook-url', // Branding title: 'Your Company Support', titleIcon: '🤖', placeholder: 'Ask us anything...', // User Experience welcomeMessage: 'Hello! 👋 Welcome to our company. How can we help you today?', starterPrompts: [ 'What services do you offer?', 'ODM/OEM process information', 'Request a quote', 'Contact support' ], // Visual Identity avatars: { bot: '🤖', user: '👤', enabled: true }, // Brand Theme Colors theme: { primaryColor: '#667eea', // Your brand color secondaryColor: '#764ba2', // Accent purple chatBg: '#f7f8fc', // Light background userMessageColor: '#ffffff', botMessageBg: '#ffffff', botMessageColor: '#333333', fontFamily: '"Inter", -apple-system, BlinkMacSystemFont, sans-serif' }, // Interactive Elements button: { enabled: true, icon: '💬', radius: '50%', shadow: '0 6px 20px rgba(102, 126, 234, 0.3)' }, tip: { enabled: true, text: 'Questions about our company? Chat now! 💬', delay: 2000, background: '#ffffff', color: '#333333' } };

🎨 Key Branding Elements

  • Brand Colors: Purple gradient matching your brand identity
  • Custom Title: "Your Company Support" instead of generic "Chat"
  • Contextual Prompts: Specific to your services and offerings
  • Professional Font: Inter font for modern, clean look
  • Consistent Styling: All elements use your brand colors

✨ How to Match Your Brand

  1. Get your brand colors: Primary and secondary hex codes
  2. Set theme.primaryColor: Your main brand color
  3. Set theme.secondaryColor: Your accent/secondary color
  4. Customize title: Use your company/product name
  5. Update prompts: Match your actual services/offerings
  6. Add logo avatar (optional): Use your logo as bot avatar
  7. Set font (optional): Use your brand's font family
  8. Test: Check on your actual website background

🎯 Quick Brand Setup

Replace these values with your brand's:

theme: { primaryColor: '#YOUR_PRIMARY_COLOR', // e.g., '#667eea' secondaryColor: '#YOUR_SECONDARY_COLOR', // e.g., '#764ba2' chatBg: '#YOUR_BG_COLOR', // e.g., '#f7f8fc' fontFamily: '"YOUR_FONT", sans-serif' // e.g., 'Inter' }

That's all you need for basic brand matching! The library handles the rest automatically.

🚀 Ready to Deploy?

Copy the configuration above, replace the chatUrl with your n8n webhook, and you're ready to go!
