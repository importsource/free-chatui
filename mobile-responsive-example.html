📱 Mobile Responsive Design

Try it now!
• On desktop: Click the chat button - see a floating widget
• On mobile (or resize your browser to <768px): Click the button - see full-screen chat!
• The chat automatically adapts - no configuration needed!

🎯 How It Works

The chat widget uses CSS media queries to detect screen size and automatically adjusts its appearance. You don't need to configure anything - it just works!

🖥️ Desktop (>768px)

  • Floating widget
  • 400px × 600px
  • Bottom-right corner
  • Rounded corners
  • Toggle button

📱 Mobile (≤768px)

  • Full-screen
  • 100% × 100%
  • Edge-to-edge
  • Maximum space
  • Better typing

📲 Small Mobile (≤480px)

  • Optimized fonts (13px)
  • Compact buttons
  • Better touch targets
  • Efficient spacing

✨ Mobile Breakpoints

/* Desktop and Tablets (landscape) */ @media (min-width: 769px) { // Widget mode: 400px × 600px // Bottom-right floating widget } /* Tablets and Mobile */ @media (max-width: 768px) { // Full-screen mode: 100% × 100% // Edge-to-edge chat window } /* Small Mobile Devices */ @media (max-width: 480px) { // Optimized font sizes // Compact spacing // Better touch targets }

🔧 Testing Responsive Design

Option 1: Browser DevTools

  1. Open browser DevTools (F12)
  2. Toggle device toolbar (Ctrl/Cmd + Shift + M)
  3. Select different devices (iPhone, iPad, etc.)
  4. Watch the chat adapt automatically

Option 2: Resize Browser

  1. Make your browser window narrow (<768px)
  2. Click the chat button
  3. See it go full-screen!
  4. Widen the window again - back to widget mode

Option 3: Real Device

  1. Open this page on your phone
  2. Click the chat button
  3. Experience native full-screen chat

💡 Why Full-Screen on Mobile?

  • More space: Mobile screens are small - use all available space
  • Better UX: Users can see more messages and type comfortably
  • Keyboard friendly: More room when keyboard appears
  • Standard pattern: Matches user expectations from apps
  • Accessibility: Larger touch targets, easier navigation
