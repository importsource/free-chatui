🎤 Voice Input Support

This example demonstrates the new voice input feature:

  • Speech Recognition: Click the microphone button to speak your message
  • Real-time Transcription: See your speech converted to text in real-time
  • Visual Feedback: Button changes color and pulses when recording
  • Error Handling: Clear error messages for common issues
  • Browser Support: Works with Chrome, Edge, Safari (with limitations)
  • Language Support: Configurable language recognition
Try it: Click the chat button to open the chat, then click the microphone button (🎤) next to the input field to start voice input. Speak your message and watch it appear as text!
Browser Requirements:
• Voice input works best in Chrome and Edge browsers
• Safari has limited support
• Firefox does not support Web Speech API
• Requires HTTPS connection for microphone access
Example Configuration: 
voice: {
  enabled: true,              // Enable voice input
  language: 'en-US',         // Speech recognition language
  continuous: false,         // Continuous recognition
  interimResults: true,      // Show interim results
  maxAlternatives: 1         // Number of alternatives
}
Supported Languages:
• English: 'en-US', 'en-GB', 'en-AU'
• Spanish: 'es-ES', 'es-MX'
• French: 'fr-FR', 'fr-CA'
• German: 'de-DE'
• And many more! Check browser documentation for full list.
