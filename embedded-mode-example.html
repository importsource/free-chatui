🔗 Embedded Mode Example

This example demonstrates how to embed the N8N Chat UI directly into your page layout, rather than as a floating widget.

🎯 Key Benefits of Embedded Mode:
  • Integrated Layout: Chat becomes part of your page design
  • Always Visible: No toggle button needed - chat is always accessible
  • Custom Positioning: Place the chat anywhere on your page
  • Responsive Design: Adapts to your layout and screen size

📊 Mode Comparison

Feature Floating Mode Embedded Mode
Position Fixed bottom-right Custom container
Toggle Button ✅ Yes ❌ No (always visible)
Layout Integration Overlays content Part of page layout
Customization Limited positioning Full control
Use Case Quick support widget Dedicated chat page/section

🔧 Implementation

1. Create Container

<!-- Create a div where you want the chat to appear -->
<div id="my-chat-container"></div>

2. Configure & Initialize

<script src="n8n-chat.js"></script>
<script>
const embeddedChat = new N8NChatUI({
  chatUrl: 'YOUR_N8N_WEBHOOK_URL',
  containerId: 'my-chat-container', // Target your div
  title: 'Support Chat',
  placeholder: 'Type your message...',
  
  // Disable toggle button for embedded mode
  button: {
    enabled: false
  },
  
  // Customize window for embedded layout
  window: {
    position: 'static',
    width: '100%',
    height: '600px',
    boxShadow: 'none',
    borderRadius: '0'
  },
  
  // Enable all features
  voice: { enabled: true },
  fileUpload: {
    enabled: true,
    uploadUrl: 'YOUR_UPLOAD_URL',
    downloadUrl: 'YOUR_DOWNLOAD_URL'
  }
});

embeddedChat.init();
</script>

3. Custom Styling (Optional)

<style>
/* Custom styles for embedded chat */
#my-chat-container .n8n-chat-widget {
  position: static !important;
  width: 100% !important;
  height: 600px !important;
  box-shadow: none !important;
  border: 1px solid #e9ecef;
}
</style>
💡 Pro Tip: Set button.enabled: false to remove the toggle button and make the chat always visible in embedded mode.

🎨 Use Cases

Perfect for:

  • Dedicated Support Pages: Full-page chat experience
  • Dashboard Integration: Chat as part of admin panels
  • Sidebar Chat: Persistent chat in page sidebar
  • Mobile Apps: Native-feeling chat interface
  • Custom Layouts: Chat positioned exactly where you want
