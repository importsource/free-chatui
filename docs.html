📖 README

Complete guide to Free Chat UI Library

N8N Chat Library 💬

A lightweight, easy-to-use JavaScript library for integrating n8n chat workflows into your web applications. Just ONE file, set your chatUrl, and you're ready to go!

<!-- Super simple - just 1 script tag! -->
<script>
  window.N8N_CHAT_CONFIG = {
    chatUrl: 'YOUR_URL',
    title: 'Support',
    titleIcon: '💬',
    welcomeMessage: 'Hello! 👋 How can I help?',
    starterPrompts: ['I have a question', 'I need help']
  };
</script>
<script src="https://cdn.jsdelivr.net/gh/importsource/free-chatui@v1.0.0-alpha/n8n-chat.js"></script>

✨ Features

  • 🎤 Voice Recording - Record and send voice messages with social media-style bubbles
  • 📁 File Upload - Upload images, documents, and files with drag-and-drop support
  • 🎨 Customizable Theme - Fully customizable colors, fonts, sizes, and styling
  • 🔗 Embedded Mode - Embed chat directly into your page layout
  • 📱 Responsive Design - Works perfectly on desktop, tablet, and mobile devices
  • 💬 Welcome Messages - Greet users with custom welcome messages
  • 🚀 Starter Prompts - Clickable starter prompts to help users begin conversations
  • 👤 Avatar Support - Customizable bot and user avatars (emoji or images)
  • ⚡ Easy Integration - Simple one-line integration with N8N webhooks
  • 🔧 Advanced Features - Scroll-to-bottom button, customizable footer, window sizing

⚡ Quick Start Guide

Get your chat widget up and running in under 5 minutes!

🚀 Method 1: Super Simple (Recommended)

Just add this to your HTML - the chat appears automatically:

<!-- Set your configuration -->
<script>
  window.N8N_CHAT_CONFIG = {
    chatUrl: 'YOUR_N8N_WEBHOOK_URL',
    title: 'Support Chat',
    placeholder: 'How can we help you?',
    welcomeMessage: 'Hello! 👋 How can I help?',
    starterPrompts: [
      'I have a question',
      'I need help',
      'Tell me more'
    ]
  };
</script>

<!-- Include ONE script - that's it! -->
<script src="https://cdn.jsdelivr.net/gh/importsource/free-chatui@v1.0.0-alpha/n8n-chat.js"></script>

Done! The chat widget automatically appears with:

  • ✅ Toggle button in bottom-right corner
  • ✅ Welcome message when opened
  • ✅ Clickable starter prompts
  • ✅ Full mobile responsiveness

🎯 Method 2: Manual Control

For more control over initialization:

<script src="https://cdn.jsdelivr.net/gh/importsource/free-chatui@v1.0.0-alpha/n8n-chat.js"></script>
<script>
  const chat = new N8NChatUI({
    chatUrl: 'YOUR_N8N_WEBHOOK_URL',
    title: 'Support Chat',
    placeholder: 'How can we help you?'
  });
  chat.init();
</script>

🔧 N8N Webhook Setup

Your N8N workflow should:

  1. Receive POST requests with this format:
{
  "chatInput": "User's message",
  "sessionId": "unique-session-id",
  "timestamp": "2024-10-21T10:30:00.000Z"
}
  1. Return a response in one of these formats:
// Simple string
"Bot response message"

// Or object with message field
{
  "message": "Bot response message"
}

🎨 Theme Customization Guide

Make the chat widget match your brand perfectly with comprehensive theming options.

🎯 Basic Theme Configuration

const chat = new N8NChatUI({
  chatUrl: 'YOUR_WEBHOOK_URL',
  theme: {
    primaryColor: '#007bff',
    secondaryColor: '#6c757d',
    backgroundColor: '#ffffff',
    textColor: '#333333',
    userMessageBg: '#007bff',
    botMessageBg: '#f8f9fa',
    userMessageText: '#ffffff',
    botMessageText: '#333333',
    borderRadius: '12px',
    fontFamily: 'Arial, sans-serif'
  }
});

🌈 Color Options

  • primaryColor - Main brand color
  • secondaryColor - Secondary elements
  • backgroundColor - Chat background
  • textColor - Main text color
  • userMessageBg - User message bubbles
  • botMessageBg - Bot message bubbles

  }
});
