✨ Avatar Best Practices

Do's:

  • ✅ Use emoji for simplicity and speed (no image loading)
  • ✅ Match avatars to your brand personality
  • ✅ Keep images small (under 100KB) if using URLs
  • ✅ Use square images (they'll be displayed as circles)
  • ✅ Test on different backgrounds
  • ✅ Ensure good contrast for readability

Don'ts:

  • ❌ Don't use complex emoji that may not render on all devices
  • ❌ Don't use large image files (slows down chat)
  • ❌ Don't use rectangular images (they'll be cropped)
  • ❌ Don't forget to test on mobile

Avatar Options

Emoji: Any single emoji character

bot: '🤖' or '💬' or '🎧' or '👨‍💼'

Image URL: Full or relative path to image

Text/Initials: 1-2 characters

bot: 'AI' or user: 'U'

Disable: Hide avatars

enabled: false

Dynamic Avatars

Set avatars based on user data:

// User-specific avatar const userAvatar = userProfilePicture || '👤'; window.N8N_CHAT_CONFIG = { chatUrl: 'YOUR_URL', avatars: { bot: '🤖', user: userAvatar, enabled: true } }; // Or use initials const userName = 'John Doe'; const initials = userName.split(' ').map(n => n[0]).join(''); window.N8N_CHAT_CONFIG = { avatars: { bot: 'AI', user: initials // 'JD' } };
