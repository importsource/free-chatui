💬 N8N Chat with Toggle Button

This example shows the chat with a toggle button. Look at the bottom right corner - you'll see a floating button!

Try it: Click the button in the bottom right to open the chat. Close it using the X button in the header.

Features

  • ✅ Toggle Button - Click to show/hide chat
  • ✅ Smooth Animations - Slide in/out effects
  • ✅ Customizable Button - Adjust icon, radius, border, shadow
  • ✅ Auto-hidden - Chat starts hidden with button visible
  • ✅ Close Button - X button in chat header

Button Customization Options

You can customize the button with these options:

  • button.enabled - Enable/disable button (default: true)
  • button.icon - Custom HTML/SVG icon
  • button.radius - Border radius (default: '50%' for circle)
  • button.border - Border style (default: 'none')
  • button.shadow - Box shadow (default: '0 4px 12px rgba(0,0,0,0.15)')
  • button.background - Background gradient or color

Code for This Example

Here's how this page is configured:

<script>
  window.N8N_CHAT_CONFIG = {
    chatUrl: 'https://your-n8n-webhook-url',
    title: 'Support Chat',
    placeholder: 'How can we help you?',
    button: {
      enabled: true,  // Show toggle button
      radius: '50%',  // Circular button
      shadow: '0 4px 12px rgba(0, 0, 0, 0.15)'
    }
  };
</script>
<script src="n8n-chat-client.js"></script>
<script src="n8n-chat-ui.js"></script>

Custom Icon Example

Want a custom icon? Just provide SVG or HTML:

button: {
  icon: '<svg...>your custom svg</svg>',
  // or use emoji
  icon: '<span style="font-size: 32px">💬</span>'
}

Disable Button (Always Show Chat)

To disable the button and always show the chat:

button: {
  enabled: false
}
