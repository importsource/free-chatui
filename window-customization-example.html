🪟 Window Customization

This example demonstrates the new window customization feature:

  • Size Control: Customize width, height, min/max dimensions
  • Visual Styling: Border radius, box shadow, border styles
  • Positioning: Fixed, absolute, or relative positioning
  • Z-Index Control: Layer management for complex layouts
  • Responsive: Mobile overrides for optimal mobile experience
Try it: Click the chat button to see the default window, then try the different window styles below!
Example Configuration: 
window: {
  width: '500px',           // Default: '400px'
  height: '700px',          // Default: '600px'
  maxWidth: '600px',        // Default: '400px'
  maxHeight: '90vh',        // Default: '80vh'
  minWidth: '350px',        // Default: '300px'
  minHeight: '500px',       // Default: '400px'
  borderRadius: '20px',     // Default: '12px'
  boxShadow: '0 8px 32px rgba(0,0,0,0.3)', // Custom shadow
  border: '2px solid #667eea', // Custom border
  position: 'fixed',        // Default: 'fixed'
  zIndex: 10000            // Default: 9999
}
Use Cases:
• Large Chat: Increase width/height for more content
• Compact Chat: Smaller dimensions for sidebar integration
• Custom Styling: Match your brand with custom borders/shadows
• Layout Integration: Use absolute/relative positioning for embedded layouts
