📝 Auto-Expanding Input Field

Try it now! Click the chat button in the bottom right corner, then:
  • Type a message normally
  • Press Shift+Enter to add new lines
  • Watch the input field grow automatically!
  • When it reaches max height, a scrollbar appears
  • Press Enter to send

🚀 How It Works

Key Features:

  • ✅ Auto-expands: Input grows as you type multiple lines
  • ✅ Max height: Configurable maximum (default: 120px)
  • ✅ Scrollbar: Appears when content exceeds max height
  • ✅ Auto-resets: Returns to single line after sending
  • ✅ Keyboard shortcuts: Enter to send, Shift+Enter for new line
  • ✅ Smooth transitions: Height changes smoothly
  • ✅ Mobile friendly: Works great on touch devices

⌨️ Keyboard Shortcuts

  • Enter → Send message
  • Shift+Enter → New line (multi-line message)

🎨 Configuration

Customize the maximum input height:

Default (120px - about 5-6 lines):

maxInputHeight: 120

Larger (200px - about 8-10 lines):

maxInputHeight: 200

Smaller (80px - about 3-4 lines):

maxInputHeight: 80

Very large (300px - about 12-15 lines):

maxInputHeight: 300

📝 Complete Example

window.N8N_CHAT_CONFIG = { chatUrl: 'YOUR_URL', title: 'Support Chat', placeholder: 'Type your message... (Shift+Enter for new line)', maxInputHeight: 150, // Custom max height welcomeMessage: 'Hello! 👋', starterPrompts: ['Help', 'Info'] };

💡 Use Cases

When to Use Larger Max Height (200px+):

  • Technical support (users need to provide detailed information)
  • Feedback forms (users writing detailed feedback)
  • Bug reports (detailed descriptions needed)
  • Customer testimonials
  • Any scenario requiring longer messages

When to Use Smaller Max Height (80px):

  • Quick Q&A chats
  • Simple support queries
  • Mobile-first interfaces
  • When space is limited
  • Quick replies expected

Default (120px) Best For:

  • General purpose chats
  • Customer support
  • Sales inquiries
  • Most common use cases

🔧 Technical Details

How Auto-Resize Works:

  1. User types in textarea
  2. JavaScript detects input event
  3. Calculates content height (scrollHeight)
  4. Compares with maxInputHeight
  5. Sets height to minimum of content or max
  6. Smooth CSS transitions applied

Scrollbar Behavior:

  • No scrollbar when content fits
  • Scrollbar appears when exceeding max height
  • Custom styled scrollbar (webkit browsers)
  • Fallback to default on other browsers
