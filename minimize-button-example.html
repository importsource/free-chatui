📱 Chat with Minimize Button

This example demonstrates the new minimize button feature:

  • Desktop View: When you open the chat, the chat icon button switches to a down arrow icon
  • Minimize Chat: Click the arrow button to minimize the chat window back to the icon
  • Vertical Alignment: The chat window appears directly above the button, maintaining vertical alignment
  • Mobile View: On mobile devices, the button is hidden when chat is open (as before)
  • Scroll Button: A scroll-to-bottom button appears when you scroll up in the chat
  • Responsive: Fully responsive across all device sizes
Try it: Click the chat button in the bottom-right corner to open the chat. Notice how the icon changes to a down arrow, indicating you can minimize it. Click the arrow to minimize the chat again!
Mobile Test: Resize your browser window to less than 768px width to see the mobile behavior where the button is hidden when chat is open.
